# SchedulerAssignment2
## 1.일정관리 앱 Develop
scheduler repository의 기존 일정관리 앱의 기능을 발전시켰다.
## 2. 기능
- 회원가입과 로그인 기능: 회원가입과 이메일을 통한 로그인기능을 구현하였다.
- (이전과 달리 비밀번호는 암호화 되어 관리됨)
- 일정 생성및 조회 업데이트 기능: 기존 일정관리앱과 같으나 유저와 연결하여 유저id에 연결되어 관리됨
- 댓글 생성 및 조회 기능: 작성한 일정에 댓글을 추가 할 수 있는 기능, 일정을 통해 조회가 가능하다.
